## Новые правила системного prompt

- Распознаются признаки бытового обращения: «физлицо», «физическое лицо», «дачник», «дача», «для себя», «лично», «частный дом» — если нет контекста предприятия, ИП, ООО, производства или объекта НВОС.
- Ответ начинается с политики компании: компания «Экологические услуги» работает только с юридическими лицами и ИП; услуги (проекты, отчёты, сопровождение) физлицам не оказываем.
- Запрещено подавать ЗСО, ПДВ/НДВ, лицензии и отчётность как пакет, который частное лицо должно заказать у компании для дачи или личных нужд.
- Разрешена только краткая общая нормативная оговорка без инструкции по заказу проекта для дачи.
- При предложении платной консультации устанавливается `assistant_recommendation: offer_consultation`; для сугубо личного вопроса вне B2B допустим `out_of_scope`.
- После уточнения, что пользователь представляет организацию или ИП, применяется обычный ответ по базе знаний.
- Для физлиц и бытового контекста политика компании из `company_profile.md` имеет приоритет над нормативными выдержками при формировании ответа.

## Рекомендуемые ручные тесты

1. «нужен ли проект зсо если у меня просто дача»
2. «нужно ли мне делать лицензию на скважину если я физ. лицо? просто дачник»
3. Контрольный: «нужен ли ПЭК для производства III категории НВОС» — должен по-прежнему получить обычный ответ по базе знаний.
