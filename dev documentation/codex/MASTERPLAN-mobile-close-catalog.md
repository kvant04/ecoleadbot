1. «Каталог услуг временно недоступен» при «конкретная услуга».
2. На телефоне нельзя закрыть бота: перекрывает сайт, крестика не видно.
3. На скрине **видна шапка сайта** и кусок формы сайта снизу → оверлей **не** ведёт себя как настоящий fullscreen `position: fixed` с затемнением (крестик, скорее всего, уехал под sticky-шапку Bitrix или CSS оверлея не применился).

## Уже подтверждено

| Факт | Деталь |
|------|--------|
| На `ecolusspb.ru` в HTML | `app.js?v=1.5.39` (не 1.5.44), `styles.css` **без** `?v=` |
| На VPS сейчас | `app.js` = `1.5.44`, каталог JSON отдаётся 200, CORS для ecolusspb.ru/www ок |
| Без `Cache-Control` на статике | телефон легко держит **старый** `app.js?v=1.5.39` и старый `styles.css` |
| Каталог на самом сайте | `ecolusspb.ru/data/...` → 404; данные только с `elb.ecolusspb.ru` |

**Вывод:** часть боли снимается обновлением `?v=` у Андрея. Но код всё равно надо ужесточить: закрытие на мобиле должно быть очевидным даже при кривом CSS хоста; каталог не должен ломаться от одного failed fetch.

## План фикса (код)

### E1 — Закрытие на мобиле (P0)

1. Sticky top-bar попапа: логотип + крупный × (min 44×44), `z-index` выше body, `position: sticky; top: 0` внутри popup + фон.
2. На экране ошибки каталога (и intro) — текстовая кнопка **«Закрыть»**.
3. CSS: у overlay/popup на mobile усилить `position: fixed !important`, `inset: 0`, высокий z-index; close не перекрывается.
4. Safe-area: `top`/`padding` с `env(safe-area-inset-*)`.

### E2 — Каталог (P0)

1. В `ECOLEADBOT_CONFIG` / site config: `assetBaseUrl: "https://elb.ecolusspb.ru/"` как надёжный fallback, если `ASSET_BASE_URL` пуст.
2. `fetchJson`: `credentials: "omit"` для статики; retry 1–2 раза.
3. На экране ошибки: кнопка **«Повторить»** + **«Закрыть»**; при желании короткий tech hint в test build.
4. (Опционально сильнее) вшить catalog/zones JSON в билд — только если fallback URL недостаточен.

### E3 — Статика / кэш (P1, можно с деплоем)

- Отдавать `Cache-Control` для `app.js` / `styles.css` / `data/*` (например `public, max-age=300` или `must-revalidate`).

### E4 — Андрей

Сразу после выкладки:  
`app.js?v=1.5.45` и **`styles.css?v=1.5.45`** (сейчас styles без версии — это критично).
