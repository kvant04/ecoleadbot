## H1 — Стоп для физлиц

**Где:** экран `client_terms` («Условия сотрудничества»), `widget/src/03a-document-gates.js`.

**Сейчас:** 2 вопроса (договор / аванс) → стопы `disqualified_procurement` / `disqualified_no_advance`.  
На контактах только дисклеймер про юрлиц/ИП — без стопа.

**Сделать:**

1. Добавить **первый** (или третий — предпочтительно **первым**) вопрос:
   - Текст: **«Вы обращаетесь как?»**
   - Варианты (single):
     - `Юридическое лицо или ИП`
     - `Физическое лицо (лично / дача / для себя)`
   - id ответа: `client_entity_type` (или аналог, единообразно с `client_contract` / `client_prepayment`).

2. Новый gate `disqualified_individual`:
   - title: **«Работаем с организациями и ИП»**
   - body: кратко — компания не оказывает услуги физлицам (документы по предпринимательской деятельности). Можно воспользоваться платной консультацией ведущего эколога.
   - Кнопка/ссылка: **«Консультация ведущего эколога»** →  
     `https://ecolusspb.ru/services/konsultatsiya-ot-vedushchego-ekologa/`  
     (`target="_blank"`, `rel="noopener noreferrer"`).
   - Без отправки лида в CRM (как у существующих disqualified-гейтов).
   - `track("client_gate_shown", { gate_id: "disqualified_individual", ... })` / gtm_event по аналогии.

3. `evaluateClientTermsGate()`: если выбран физлицо → этот gate **до** проверки закупки/аванса.

4. Payload / ES scoring: сохранить ответ `client_entity_type` в `client_terms_answers` (уже уходит блоком).

**Не делать:** VK/MAX; отдельный wizard вне client_terms.

## H3 — «Пройти заново» в production

**Почему:** клиент не знает про другой браузер; «Назад» долго; через месяц нужен чистый старт.

**Сделать:**

1. Показать кнопку **«Пройти заново»** в production (не только `IS_TEST_BUILD`) на:
   - `renderContactBlocked` (заявка уже отправлена);
   - финальный экран успеха (`renderFinal` / success) — если ещё нет.
2. По клику — существующий `resetSessionForRetest()` (или вынести в `resetSessionToIntro()` без test-only ограничений): очистка state/session → intro.
3. **Anti-duplicate 60 мин** остаётся: повторная **отправка** лида по-прежнему блокируется окном; кнопка только сбрасывает опрос/UI. Если `isAlreadySubmitted()` — после reset при попытке снова дойти до контактов снова blocked до истечения окна (ожидаемо). Опционально: на blocked-экране подпись «Новую заявку можно отправить через ~N мин» — nice-to-have, не блокер.
4. Не показывать на каждом промежуточном экране (mini_teaser и т.д.) — только финал / blocked, плюс при желании одна вторичная ссылка на intro после success.
