# Примеры payload EcoLeadBot v1.4

Тестовые JSON для n8n / Bitrix. Имена и телефоны — вымышленные.

| Файл | Сценарий |
|------|----------|
| `payload-main-flow-v14.json` | Основной flow → мини-оценка (автосервис, 3 зоны) |
| `payload-document-service-v14.json` | Каталог → ПЭК, категория НВОС II, 2–3 площадки |

Как получить payload из браузера вручную:

1. `py server.py` → http://127.0.0.1:8000 → **Ctrl+F5**
2. Пройти сценарий до контактов
3. **F12** → вкладка **Console**
4. Отправить заявку — появится строка `[EcoLeadBot] payload →` с объектом (на localhost данные не маскируются)
5. ПКМ по объекту → **Copy object** / «Сохранить как…»

На production-сайте в консоли контакты будут `[hidden]` — тестируйте на localhost.
